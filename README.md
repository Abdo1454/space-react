# Space Tourism React

A modern multi-page space tourism website built with React, inspired by the Frontend Mentor Space Tourism Challenge.

## Features

* Responsive design for mobile, tablet, and desktop
* React Router navigation
* Interactive user interface
* Modern component-based architecture
* Optimized production build

## Tech Stack

* React
* React Router
* JavaScript
* CSS3
